# 📵 THE FEED

> 알고리즘이 던져주는 자극적인 콘텐츠의 “먹이(FEED)”와, 이에 중독되어 피폐해지는 사람들을 함께 의미하는 공포/스릴러 시뮬레이션 게임입니다.

---

## 📖 프로젝트 소개

**THE FEED**는 SNS 알고리즘 중독의 위험성을 플레이어가 직접 체험하도록 설계한 성찰형 게임입니다.

플레이어는 컴퓨터 화면에서 SNS 쇼폼 플랫폼인 **THE FEED**에 접속해 콘텐츠를 시청하고, 일부 콘텐츠와 연결된 미니게임을 진행합니다. 콘텐츠를 반복해서 소비할수록 정신력이 감소하며, 일정 수치 이하가 되면 UI와 쇼폼 콘텐츠가 기괴하게 변화합니다.

익숙한 SNS 인터페이스에서 시작하지만, 알고리즘에 계속 노출될수록 화면과 콘텐츠가 비정상적으로 변하는 과정을 통해 SNS 중독의 위험성을 표현했습니다.

---

## 🎮 게임 플레이

* **장르:** 공포 / 스릴러 시뮬레이션
* **플레이 인원:** 1인
* **플랫폼:** PC
* **타깃 플레이어:** SNS 알고리즘 콘텐츠에 많은 시간을 사용하는 사용자

### 게임 진행 흐름

```text
컴퓨터 화면 실행
→ THE FEED 접속
→ 쇼폼 콘텐츠 3개 노출
→ 콘텐츠 시청 또는 연결된 미니게임 진행
→ 정신력 감소
→ 새로고침 후 새로운 콘텐츠 노출
→ 정신력 임계치 도달
→ UI 및 쇼폼 콘텐츠 기괴화
```

### 핵심 재미 요소

* 익숙한 SNS 화면 안에서 점차 나타나는 이질감
* 다음 콘텐츠를 예측하기 어려운 불안감
* 반복적인 콘텐츠 소비와 미니게임을 통한 중독 체험
* 정신력 수치에 따라 달라지는 화면 연출과 사운드

## ⚙️ 주요 기능

### 1. SNS 쇼폼 시스템

실제 SNS와 유사한 홈, 피드, 검색, 설정 형태의 UI를 구성했습니다. 플레이어는 쇼폼 콘텐츠를 선택하고 시청하며, SNS를 사용하는 것과 비슷한 흐름으로 게임을 진행합니다.

### 2. 정신력 시스템

콘텐츠 시청과 미니게임 진행에 따라 정신력이 감소합니다. 정신력이 일정 수치 이하로 내려가면 UI가 왜곡되고, 쇼폼 콘텐츠가 부정적이고 기괴한 형태로 변화합니다.

### 3. 미니게임 시스템

일부 쇼폼 콘텐츠는 미니게임과 연결됩니다. 플레이어는 콘텐츠를 시청하는 과정에서 미니게임을 발견하고 진행하며, 이 과정에서도 정신력이 소모됩니다.

현재 총 5종의 미니게임 시스템을 제작했습니다.

### 4. 새로고침 및 뒤로가기 시스템

한 번에 3개의 쇼폼 콘텐츠가 노출되며, 해당 콘텐츠를 모두 시청하거나 연결된 게임을 클리어해야 새로고침이 가능합니다.

이 기능을 통해 플레이어가 콘텐츠를 계속 소비하게 되는 구조를 구현했습니다.

### 5. 기괴화 연출 및 사운드

정신력이 감소하면 정상 상태의 UI가 왜곡되고, 불안감을 주는 이미지와 쇼폼 콘텐츠가 등장합니다. 기본 배경음악, 클릭음, 충돌음, 상태 변화 후 배경음악 등을 적용해 몰입도를 높였습니다.

## 💡 기획 의도

SNS 알고리즘은 사용자의 관심을 끌 수 있는 콘텐츠를 반복적으로 추천하며, 사용자는 의도하지 않아도 계속해서 다음 콘텐츠를 소비하게 됩니다.

THE FEED는 이러한 구조를 단순히 설명하는 대신, 플레이어가 직접 SNS 화면을 조작하고 쇼폼 콘텐츠와 미니게임을 반복적으로 경험하도록 설계했습니다. 이를 통해 플레이어가 자신의 SNS 사용 습관과 알고리즘 중독의 위험성을 생각해 볼 수 있도록 하는 것이 프로젝트의 목표입니다.

## 📝 개발 과정 및 회고

개발 과정에서 기존 UI를 게임 화면에 맞게 전체적으로 보완하고, 쇼폼 콘텐츠 수를 늘렸습니다. 기존 콘텐츠 외에 추가 쇼폼 30개와 기획 쇼폼 15개를 제작했으며, 쇼폼과 연동되는 미니게임 5종을 구현했습니다.

개발 중에는 기능을 추가할 때 기존 기능이 영향을 받거나, 화면 크기와 UI 글자 크기가 모니터 환경에 따라 맞지 않는 문제가 발생했습니다. 코드 수정과 화면 크기 고정 기능을 통해 이를 보완했습니다.

현재는 더 자연스러운 UI 연출, 다양한 미니게임, 세부 시스템 확장, 플레이 시간 증가, 명확한 게임 종료 시스템이 추가로 필요한 상태입니다.
